<!--Featured Projects Section-->
<h2 align="center">Featured Projects</h2>

**QasimOS, Interactive Portfolio**
Personal interactive portfolio site, styled as a Windows 11 style desktop experience with a working terminal, a project explorer, and an Ask Qasim assistant.
Stack: TypeScript
Repository: https://github.com/itx-zuberi/qasim-s-os
Live: https://qasimzuberi.vercel.app/

**HISN, CTI Based Intrusion Detection and Prevention System**
Flagship IDS/IPS product built at Qararix. Combines Cyber Threat Intelligence based detection, CIDR based IP filtering, and automated response for real time network defense. Integrates IoT sensors for network telemetry and uses packet level monitoring with rule based signatures to detect and block malicious TCP/UDP traffic. Ranked Top 10 in Accelerate Punjab, an incubation program by the Punjab Information Technology Board.
Stack: Python, Suricata, Snort, IoT, TCP/IP

**SentriQ, Remote Laptop Security and Anti Intrusion Platform**
A multi component desktop, mobile, and cloud platform that detects unauthorized access to an unattended laptop and lets the owner remotely lock, sleep, shut down, or trigger an alarm, positioned around active prevention rather than post theft recovery.
Stack: Product Concept, Cloud Messaging, Cross Platform

**NeuralAge, Region Aware Facial Aging Research Platform**
An age and gender classification pipeline feeding a Stable Diffusion image to image generator with hand tuned, gender and age specific prompts for realistic, identity preserving age progression across five age bands.
Stack: PyTorch, timm, Stable Diffusion, Diffusers

**AI Powered Retail Surveillance System, Hybrid Suspicious Activity Detection**
A three stage research pipeline unifying detection, multi object tracking, and behavior analysis across five public datasets (COCO, SKU-110K, MOT17/20, AVA, UCF-Crime) for retail loss prevention analytics, with resilient dataset acquisition and bounding box aware augmentation.
Stack: PyTorch, ViT/DETR, HuggingFace, Albumentations

**Stroke Risk Prediction Dashboard**
An artificial neural network trained on 14 clinical and demographic features to output a stroke risk probability, served through a FastAPI dashboard with automatic feature alignment and scaling.
Stack: TensorFlow/Keras, FastAPI, scikit-learn

**Multi Step Sales Forecasting with Deep Learning**
A course project comparing LSTM, GRU, Bidirectional LSTM, and Transformer architectures on the Kaggle M5 dataset, including optimizer and hyperparameter sensitivity studies.
Stack: TensorFlow, LSTM/GRU/Transformer

**MedicalZone, Multi Role Healthcare Android Application**
A role based (patient, doctor, admin) healthcare app covering appointment booking, medicine e-commerce, lab test and report viewing, and inventory management across isolated SQLite data domains.
Stack: Java, Android SDK, SQLite, Firebase

**Child Safety Band, Wearable Companion App**
A BLE connected Android app for a GPS child safety wristband with live OpenStreetMap tracking, multi child Room database support, and geofence and SOS triggered WhatsApp alerting.
Stack: Java, BLE, osmdroid, Room, WhatsApp Alerts

**HuMotion, AI Powered Smart Prosthetic Arm**
A prosthetic arm prototype that translates EMG muscle signals into natural movement via an AI recognition model and microcontroller driven actuation, reaching an 11 kg lifting capacity in testing.
Stack: Embedded Systems, EMG Sensors, AI Pattern Recognition

**SheSafe by Qararix, Women Safety System**
A safety application with real time GPS tracking and automated emergency notification via SMS and calls, with Firebase based alerting and health monitoring for rapid emergency communication.
Stack: Android, Firebase, GPS, IoT Monitoring
Repository: https://github.com/itx-zuberi/shesafebyqararix

**AI Document Summarizer**
A self hosted, privacy friendly summarization microservice supporting PDF, Word, PPT, and text ingestion through a locally run LLM, with history and re-summarization endpoints.
Stack: FastAPI, LangChain, Ollama (local LLM)

**Animora Nexus, Anime Catalogue Management System**
A normalized MySQL schema paired with a full REST API covering anime, genre, and episode CRUD, ratings, watch history, and subscriptions for a single page front end.
Stack: Node.js, Express, MySQL

**Ethereum Smart Contract Suite and MetaMask Dashboards**
Three Solidity contracts (ScholarshipFund, CrowdFunding, VotingSystem) implementing access control, payable fund custody, deadline and goal logic, and refund mechanics, paired with wallet connected front end dashboards for live contribution, withdrawal, refund, and donation status tracking.
Stack: Solidity, ethers.js, MetaMask
